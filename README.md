## Overview

Step-by-step pandas exercises exploring an Olympics medals dataset: shape, filtering, grouping, sorting and summary statistics.

## Features

- Nine short scripts (`1.py` to `9.py`), each answering one question about the data
- Covers loading CSVs, filtering, grouping, sorting and aggregations
- Dataset included (`olympics.csv`)

## Tech stack

Python · pandas

## Getting started

```bash
pip install pandas
python 1.py
```

## Project structure

`1.py` ... `9.py` exercises · `olympics.csv` data
